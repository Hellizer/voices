# голоса

Hellizer/voices

Локальное приложение-спутник для одного пользователя. Персонаж живёт в фоновом процессе на локальном сервере, автономно, реагирует на редкие вмешательства игрока. Состояние сохраняется на диск.

## что это

Не игра в привычном смысле. Не тамагочи. Персонаж — это набор конкурирующих голосов, история следов и самоназваний. Игрок — внутренний голос-советник, который сдвигает веса, но не приказывает. Развитие — не оптимизация, а дифференциация, кристаллизация и мутация.

## что внутри

- sim/voices.py — шесть голосов, их веса и связи.
- sim/traces.py — девять типов следов.
- sim/actions.py — реестр действий, оценка и выбор.
- sim/world.py — локации, окна возможностей, NPC.
- sim/memory.py — журнал событий и влияние памяти.
- sim/mutate.py — пороги, кризисы, шрамы, самоназвания.
- sim/player.py — короткий, длинный и косвенный каналы влияния игрока.
- sim/character.py — контейнер состояния персонажа.
- sim/loop.py — один такт симуляции.
- storage/repository.py — SQLite.
- storage/backups.py — два чередующихся файла бэкапа.
- api/runtime.py — состояние процесса, асинхронный цикл, рассылка подписчикам.
- api/routes.py — REST.
- api/ws.py — WebSocket.
- frontend/ — статический клиент.
- tools/smoke.py — оффлайн-прогон без сервера.
- tools/inspect_state.py — просмотр содержимого SQLite без запуска сервера.

## требования

- Windows, PowerShell.
- Python 3.12, команда py.

## установка

```
cd voices
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

## запуск

```
py main.py
```

Сервер поднимается на 127.0.0.1:8000. Браузер открывает http://127.0.0.1:8000/. Симуляция идёт независимо от браузера.

## конфигурация

Всё в config.yaml. Такт по умолчанию — один игровой час за десять реальных минут. Бэкапы — два чередующихся файла state-a.json и state-b.json в backups/, пишутся каждый такт, при сбое БД берётся самый свежий валидный.

## оффлайн-прогон

```
py tools/smoke.py --ticks 200 --seed 42
```

Прогоняет N тактов в памяти и печатает статистику: количество кризисов, следов, топ действий, веса голосов. Полезно для быстрой проверки, что персонаж не залипает.

## просмотр состояния

```
py tools/inspect_state.py --db state.db
```

Читает SQLite и печатает голоса, следы, NPC, окна, последние события.

## REST

- GET /state — полный снапшот.
- GET /events?since=N — журнал с такта N.
- POST /intervene — короткое вмешательство. Тело: {"type": "...", "target": "...", "intensity": 0.2}. Типы: request, forbid, support, distract, insist, leave.
- POST /environment — длинное вмешательство. Тело: {"type": "...", "payload": {...}}. Типы: teach, connect, value, open_door, close_door.
- POST /tick — ручной такт.
- GET /backups — список двух файлов бэкапа.
- POST /backup — ручной бэкап.

## WebSocket

/ws. Пуши: hello, tick, trace, crisis, intervention_result, world_change. Формат — JSON, поле type.

## тесты

```
py -m pytest -q
```

## что не входит

- LLM и ИИ.
- Мультиплеер.
- Достижения и FOMO.
- Мобильный клиент.
- Социальные функции.
- Откат сюжета через бэкапы.
